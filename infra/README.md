# Agent Landing Zone infrastructure

Deploy from the [repository root](../README.md), not from `infra/`. This is
repository-owned foundation source with two co-maintained providers:

```text
infra/
  bicep/       main.bicep, main.parameters.json, modules/, constants/
  terraform/   Terraform composition, pinned modules, provider lock and tests
  shared/      roles.json and abbreviations.json used by both providers
  tests/       Offline compiled-template contracts, script tests and fixtures
  LICENSE      Incorporated foundation attribution
scripts/infra/ Infrastructure helpers (at the repository root)
```

The root [`main.parameters.json`](../main.parameters.json) and
[`manifest.json`](../manifest.json) are authoritative. `infra.source` records
the incorporated Bicep provenance; deployment uses local source, not a download
of that version. Bicep's tracked parameter seed is regenerated by preprovision.
Terraform's generated `shared/main.parameters.json` is diagnostic-only, ignored
by Git, and is not a Terraform input or a second product configuration.

Lifecycle hooks remain in root [`scripts/`](../scripts/); their infrastructure
helpers live in [`scripts/infra/`](../scripts/infra/). See the
[offline contracts](tests/README.md), [Terraform notes](terraform/README.md)
and [layout decision and migration](../docs/adr/ADR-0032-infrastructure-source-layout.md).

For deployment and configuration, use the central
[Agent Landing Zone documentation](https://azure.github.io/AI-Landing-Zones/agent-landing-zone/):
[configuration](https://azure.github.io/AI-Landing-Zones/agent-landing-zone/configuration/),
[full stack](https://azure.github.io/AI-Landing-Zones/agent-landing-zone/deploy-full-stack/),
[infrastructure only](https://azure.github.io/AI-Landing-Zones/agent-landing-zone/deploy-infra-only/)
and [network isolation](https://azure.github.io/AI-Landing-Zones/agent-landing-zone/network-isolation/).
